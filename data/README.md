# Данные методички

Все наборы данных лежат в этом каталоге. Они синтетические: правдоподобные
по единицам и диапазонам, но не описывают реальных пациентов.

## Соглашение об именах

Основной шаблон — `NN_dataset.csv`, где `NN` — номер вида графика:

- `00_dataset.csv` — раздел 1 (принципы; иллюстрация «плохо/хорошо»);
- `01_dataset.csv` — первый вид графика (линейный), `02_dataset.csv` — второй
  (рассеяние) и т. д.;
- `02_python_dataset.csv` — служебный набор раздела 2 (сравнение библиотек),
  у него явный суффикс, чтобы не путать с `02_dataset.csv`.

Номер набора соответствует номеру папки вида графика в `05_charts/`,
а не номеру раздела. Если для одного вида графика нужно несколько наборов,
используются суффиксы: `01a_dataset.csv`, `01b_dataset.csv`.

## Реестр

| Файл | Раздел | Содержание | Строк |
|---|---|---|---|
| `00_dataset.csv` | 1 | 148 пациентов, 3 группы, САД до/после 12 недель | 148 |
| `02_python_dataset.csv` | 2 | 132 пациента, 3 группы, HbA1c до/после 12 недель | 132 |

## Правила

- Данные генерируются скриптом `make_data.py` в папке соответствующего
  раздела; ручные правки CSV не приветствуются.
- Кодировка — UTF-8, разделитель — запятая, десятичный разделитель — точка.
- Имена колонок — `snake_case`, единицы измерения — в суффиксе
  (`_mm_hg`, `_pct`, `_mg_l`, `_min`).
- Каждый набор должен воспроизводиться при фиксированном seed.
- Схемы раздела 3 (палитры, CVD, кегли) не являются графиками данных
  и не требуют CSV.

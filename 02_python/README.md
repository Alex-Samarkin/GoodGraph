# Раздел 2. Python-инструментарий

Статус: ожидает запроса. В этом разделе планируется:

- экосистема библиотек: matplotlib, seaborn, plotnine (аналог ggplot2),
  scipy, pandas, numpy — со ссылками на документацию;
- когда что использовать: императивный matplotlib против декларативного
  plotnine;
- настройка среды через `uv`: `pyproject.toml`, `uv.lock`, версии Python;
- архитектура воспроизводимого графика: данные → стиль → рисунок → экспорт;
- общий модуль `goodgraph`: палитры, rcParams, физические размеры, сохранение;
- типичные ошибки новичка и как их избежать.

Файлы появятся после запуска раздела: `python.md`, `python.typ`,
`scripts/` с примерами.

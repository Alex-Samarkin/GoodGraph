# Раздел 3. Требования к научной графике

Статус: ожидает запроса. Планируемое содержание:

- цветовые гаммы: качественные, последовательные, дивергентные;
  Okabe–Ito, Paul Tol, ColorBrewer, viridis/cividis;
- проверка на дальтонизм и градации серого;
- шрифты: гарнитуры, кегли, кириллица, математика, специальные символы;
- физические размеры: 85/114/170 мм, поля, пропорции;
- разрешение и форматы: SVG, PDF, EPS, TIFF, PNG;
- RGB и CMYK, цветовые профили;
- контраст и доступность (WCAG);
- сводные таблицы «параметр → значение → источник».

Планируемые файлы: `requirements.md`, `requirements.typ`, `scripts/`,
примеры палитр в `images/03_*`.

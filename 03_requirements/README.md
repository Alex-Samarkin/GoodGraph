# Раздел 3. Требования к научной графике

Раздел о цвете, шрифтах, размерах и форматах: конкретные значения, проверки
и чек-листы, которые можно применить перед отправкой статьи.

## Данные

Раздел **не создаёт набор данных**: рисунки 3.1–3.3 — это схемы палитр
и типографики, а не графики данных. Каждый скрипт самодостаточен и
генерирует изображение из явно заданных цветов, текста и матриц CVD.
Это не нарушает правило «свой генератор и свой датасет для вида графика»:
видов графиков данных здесь нет.

## Запуск

```bash
# из корня репозитория
uv sync
uv run python 03_requirements/scripts/plot_palettes.py
uv run python 03_requirements/scripts/plot_cvd.py
uv run python 03_requirements/scripts/plot_fonts.py
```

Или:

```bash
make figures
```

## На что смотреть в разделе

- тип палитры определяется задачей: категория, величина или отклонение;
- качественных цветов 6–8, без радуги и `jet`;
- красный/зелёный не единственные носители смысла;
- шрифт sans-serif, 7–10 pt в конечном размере;
- ширина 85/114/170 мм, проектирование сразу в конечном размере;
- вектор для линий и текста, растр для фото;
- шрифты встраиваются, цветовой профиль проверяется.

## Сборка PDF

```bash
typst compile --root . 03_requirements/requirements.typ build/03_requirements.pdf
```

Флаг `--root .` обязателен: иначе Typst не пустит файл из `03_requirements/`
к картинкам в `../images/`.

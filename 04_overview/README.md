# Раздел 4. Виды научных графиков

Обзорная карта: какие семейства графиков существуют, на какой вопрос они
отвечают и где будет подробный разбор. На карте одно семейство содержит
несколько графиков; все они получают отдельные разделы в разделе 5.
Это не практический раздел: данные, «плохие» и «правильные» примеры —
в разделе 5.

Раздел **не создаёт набор данных**: рисунок 4.1 — схематическая карта,
а не график данных. Правило «свой генератор и свой датасет» относится

## На что смотреть в разделе

- сначала вопрос, потом график;
- пять вопросов: вопрос, переменные, *n* и группы, что важнее читателю,
  что он должен прочитать;
- десять семейств и 33 отдельных графика: сравнение, распределение,
  связь, динамика, состав, матрица, выживаемость, диагностика, парные
  измерения, оценки эффекта;
- у каждого семейства есть ограничения;
- иногда таблица лучше графика;
- антипаттерны: 3D, круговая на 10 долей, столбцы с SD, две оси Y,
  ROC без prevalence, Kaplan–Meier без at-risk и др.

## Сборка PDF

```bash
typst compile --root . 04_overview/overview.typ build/04_overview.pdf
```

Флаг `--root .` обязателен: иначе Typst не пустит файл из `04_overview/`
к картинке в `../images/`.

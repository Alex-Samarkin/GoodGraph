# Раздел 4. Виды научных графиков

Статус: ожидает запроса. Планируемое содержание:

- классификация графиков по задаче: сравнение, распределение, связь,
  динамика, состав, матрица, выживаемость, диагностика;
- таблица «задача → график → ограничения»;
- когда график вводит в заблуждение и какой тип выбрать вместо него;
- связь с грамматикой графики (Wilkinson; ggplot2/plotnine);
- анатомия графика: данные, отображения, геометрия, шкалы, грани.

Планируемые файлы: `overview.md`, `overview.typ`.

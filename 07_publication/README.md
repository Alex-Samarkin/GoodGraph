# Раздел 7. Подготовка графиков к публикации

Статус: ожидает запроса. Планируемое содержание:

- требования журналов: ширина, шрифты, разрешение, форматы, цвет;
- пошаговый чек-лист перед отправкой;
- экспорт из matplotlib/seaborn/plotnine: SVG, PDF, TIFF, PNG;
- встраивание шрифтов и перевод текста в кривые;
- цветовые профили RGB/CMYK и проверка печати;
- подписи (captions) и supplementary figures;
- типичные причины отказа редакции;
- письмо редактору и ответ на замечания по рисункам.

Планируемые файлы: `publication.md`, `publication.typ`,
`scripts/export_examples.py`.

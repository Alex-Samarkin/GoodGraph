# Раздел 5. Виды графиков: данные → плохо → хорошо

Статус: ожидает запроса. Каждый вид графика — отдельная папка с полным
циклом: реалистичные данные, неудачный график, разбор ошибок, правильный
график, объяснение улучшений.

## План видов

| № | Папка | Тема | Данные |
|---|---|---|---|
| 01 | `01_line/` | линейный график, динамика | `data/01_dataset.csv` |
| 02 | `02_scatter/` | рассеяние, связь, выбросы | `data/02_dataset.csv` |
| 03 | `03_bar/` | столбцы и полосы, сравнение категорий | `data/03_dataset.csv` |
| 04 | `04_distribution/` | гистограмма, box, violin, strip | `data/04_dataset.csv` |
| 05 | `05_forest/` | forest plot, эффекты и ДИ | `data/05_dataset.csv` |
| 06 | `06_kaplan_meier/` | выживаемость, цензурирование | `data/06_dataset.csv` |
| 07 | `07_roc/` | ROC и precision–recall | `data/07_dataset.csv` |
| 08 | `08_heatmap/` | матрицы, корреляции | `data/08_dataset.csv` |
| 09 | `09_small_multiples/` | малые кратные, многомерность | `data/09_dataset.csv` |
| 10 | `10_slope/` | парные измерения, до/после | `data/10_dataset.csv` |
| 11 | `11_pie/` | круговая диаграмма: когда можно и когда нельзя | `data/11_dataset.csv` |

Порядок и состав могут меняться по запросу.

## Структура папки вида

```
05_charts/01_line/
├── README.md
├── line.md              # текст раздела
├── line.typ             # дубликат для Typst
└── scripts/
    ├── make_data.py     # → data/01_dataset.csv
    ├── bad_plot.py      # → images/05_01_bad_line.*
    └── good_plot.py     # → images/05_01_good_line.*
```

Правила:

- скрипты самодостаточны: данные пишутся в общий `data/`, рисунки — в общий
  `images/`;
- каждый рисунок сохраняется в SVG и PNG;
- плохой и правильный графики используют один и тот же CSV;
- текст и Typst-дубликат правятся одновременно.

# 5.01 Линейный график

Первый практический график: динамика САД за 12 недель в трёх группах.
Свой генератор и свой датасет; данные не переиспользуются в других
разделах.

## Файлы

| Файл | Назначение |
|---|---|
| [`line.md`](line.md) | текст раздела в Markdown |
| [`line.typ`](line.typ) | Typst-дубликат |
| [`scripts/make_data.py`](scripts/make_data.py) | генерация → `data/01_dataset.csv` |
| [`scripts/bad_plot.py`](scripts/bad_plot.py) | плохой график → `images/05_01_bad_line.*` |
| [`scripts/good_plot.py`](scripts/good_plot.py) | правильный график → `images/05_01_good_line.*` |

## Данные

`data/01_dataset.csv` — 120 пациентов, 3 группы, САД на 0/4/8/12-й неделе,
*n* = 40 в группе, 480 строк в long-формате.

| Колонка | Смысл | Единица |
|---|---|---|
| `patient_id` | идентификатор пациента | — |
| `group` | группа терапии | — |
| `week` | неделя измерения | недели |
| `sbp_mm_hg` | систолическое АД | мм рт. ст. |

## Рисунки

| Рисунок | Файлы | Что показывает |
|---|---|---|
| 5.1.1 | `images/05_01_bad_line.svg`, `.png` | обрезанная ось, светофорные цвета, тени, тяжёлая сетка |
| 5.1.2 | `images/05_01_good_line.svg`, `.png` | среднее + 95 % ДИ, Okabe–Ito, прямые подписи |

## Запуск

```bash
uv sync
uv run python 05_charts/01_line/scripts/make_data.py
uv run python 05_charts/01_line/scripts/bad_plot.py
uv run python 05_charts/01_line/scripts/good_plot.py
```

## Сборка PDF

```bash
typst compile --root . 05_charts/01_line/line.typ build/05_01_line.pdf
```

## Что важно

- линия — для времени и упорядоченной оси, не для категорий;
- ось Y может не начинаться с нуля, но не должна обрезать данные;
- среднее без ДИ скрывает неопределённость;
- прямые подписи лучше легенды;
- 85 мм, 7–9 pt, Okabe–Ito, лёгкая сетка.
